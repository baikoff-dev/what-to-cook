# Frontend «Что приготовить?»

Отдельный веб-клиент приложения на React и TypeScript. На этапе 9.5 здесь
работают просмотр и фильтрация каталога, клиентская страница рецепта и пересчёт
ингредиентов на выбранное количество порций. Рецепт можно добавить в избранное
и удалить оттуда без перезагрузки страницы. Отдельный маршрут
`/recipes/favorites` показывает сохранённые карточки и позволяет удалить их.
Остальные сценарии пока остаются в Spring MVC и Thymeleaf.

## Технологии

- React 19;
- React Router;
- TypeScript 7;
- Vite 8;
- Tailwind CSS 4;
- shadcn/ui на базе Radix;
- Vitest и React Testing Library.

## Запуск в Windows

```powershell
npm.cmd install
npm.cmd run dev
```

Приложение доступно на <http://localhost:5173>. Vite не выбирает другой порт,
если `5173` занят: это помогает сразу заметить конфликт конфигурации.

Запросы с префиксами `/api`, `/images` и `/user-images` проксируются на backend
по адресу <http://localhost:8080>. Каталог получает данные методом
`GET /api/recipes`, а варианты фильтров — методом
`GET /api/recipes/filter-options`. Страница рецепта получает подробности
методом `GET /api/recipes/{id}` и передаёт `servings` для пересчёта порций.
Избранное изменяют методы `PUT /api/recipes/{id}/favorite` и
`DELETE /api/recipes/{id}/favorite`, а список получает
`GET /api/recipes/favorites`.

Карточки открываются через клиентский маршрут `/recipes/{id}`. Ссылки на пока
не перенесённые действия открывают backend. Его адрес можно изменить переменной
`VITE_BACKEND_URL`; по умолчанию используется `http://localhost:8080`.

## Проверки

```powershell
npm.cmd run lint
npm.cmd run test
npm.cmd run build
```

`test:watch` запускает Vitest в режиме наблюдения во время разработки.

## Структура

```text
src
├── components     # общий layout и компоненты shadcn/ui
├── features       # пользовательские сценарии по предметным областям
├── lib            # общие вспомогательные функции
├── test           # общая настройка тестовой среды
├── App.tsx        # корневая композиция экранов
└── App.test.tsx   # внешние тесты поведения приложения
```

Код реальных сценариев группируется по предметным областям. Каталог, чтение
карточки, переключение и список избранного реализованы в React. Общая карточка
рецепта переиспользуется каталогом и избранным, а вычисление порций и правила
избранного остаются в Spring Boot. Остальные изменяющие действия ещё не
перенесены, поэтому интерфейс Thymeleaf сохраняется.
